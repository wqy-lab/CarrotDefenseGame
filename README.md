# 项目规划文档

## 一、总体架构与流程

### 1. 游戏总体说明

- 玩家在地图路线旁建造防御塔，阻止敌人到达终点吃掉萝卜。
- 萝卜初始10点生命，归零则游戏失败。
- 胜利条件：完成所有波次，萝卜生命大于0。

### 2. 游戏状态与界面

- **开始界面**：包含“开始游戏”、“退出”按钮。
- **关卡选择界面**：展示已解锁关卡（初始仅第一关解锁，通关后解锁下一关）。
- **战斗主界面**：显示地图、道路、萝卜位置、塔位、炮塔、怪物。
- **游戏控制**：支持暂停/继续、投降/退出战斗、重试当前关卡。
- **信息显示**（实时刷新）：
  - 当前波次 / 总波次
  - 玩家金币数量
  - 萝卜剩余生命值
  - 当前场上怪物数量（可选）

---

## 二、地图与基础世界

### 1. 地图数据

- 加载地图图片（或网格背景）。
- 定义地图网格（如 20×15）。
- 定义敌人移动路径点（路点数组）。
- 定义初始可建造塔位坐标列表。
- 定义障碍物初始位置、种类（树、石像等）、生命值、清除后奖励金币。

### 2. 障碍物与清障机制

- 障碍物可被炮塔子弹或怪物攻击（需指定可攻击障碍物的选项）。
- 障碍物生命值归零时：
  - 播放爆炸/碎裂动画。
  - 清除该格障碍物。
  - 将该格标记为可用塔位。
  - 给予玩家金币奖励。
- 清障策略意义：玩家需决定是否消耗炮塔火力清障以开辟新塔位。

### 3. 角色基类（所有活体对象共用）

- 属性：位置、当前生命值、最大生命值、是否存活、类型标识。
- 通用行为：受到伤害、死亡、更新（每帧移动或攻击）。

---

## 三、资源与经济系统

### 1. 金币管理

- **初始金币**：由关卡配置决定。
- **金币来源**：
  - 击杀怪物获得赏金。
  - 清除障碍物获得奖励。
- **金币消耗**：
  - 建造炮塔（扣除价格）。
  - 升级炮塔（扣除升级费用）。
- **出售炮塔**：返还部分金币，塔位变回空闲。

### 2. 经济UI

- 实时显示当前金币数量。
- 当金币不足时，建造/升级按钮不可用（或提示“金币不足”）。

---

## 四、炮塔系统（核心战斗元素）

### 1. 炮塔通用功能

- **等级**：每个炮塔最高3级，每级提升攻击力、攻击范围、攻击速度（若适用）。
- **目标搜索**：每隔一定帧数在射程内自动搜寻敌人。
- **转向与瞄准**：炮塔基座平滑转向目标（或瞬间面向），发射子弹。
- **操作面板**：点击已建造炮塔 → 弹出面板，提供“升级”和“出售”按钮。

### 2. 基础三种炮塔（初步计划）

| 炮塔类型             | 攻击方式                                         | 核心功能                                             | 升级提升方向                                  |
| -------------------- | ------------------------------------------------ | ---------------------------------------------------- | --------------------------------------------- |
| **近战范围减速炮塔** | 近战范围攻击（无需子弹，直接伤害范围内所有敌人） | 对范围内敌人造成伤害并附加减速Debuff（降低移动速度） | 增加伤害、扩大范围、增强减速效果              |
| **远程多发炮塔**     | 一次发射多发子弹（如3发）                        | 可攻击多个不同敌人，或对同一敌人造成多次伤害         | 增加子弹数量、提高单发伤害、增加弹射/分裂效果 |
| **远程单体高伤炮塔** | 单发子弹，高伤害                                 | 优先攻击高血量敌人，适合点杀精英怪                   | 增加暴击率、破甲、射程提升                    |

### 3. 炮塔的数据管理

- 所有炮塔的属性（价格、攻击力、范围、攻击速度、子弹属性等）按类型和等级配置在数据表中（可用JSON或硬编码初期）。

### 4. 后续扩展计划

- 基于以上三种炮塔机制进行组合或衍生，例如：
  - 近战范围 + 眩晕（强控）
  - 远程多发 + 穿透（直线AOE）
  - 远程单体 + 毒素持续伤害

## 五、刷怪与波次系统

### 1. 波次管理

- 每个关卡包含多波敌人（如5波）。
- 每波数据：怪物类型、数量、每个怪物出生间隔（秒）、波次开始前倒计时。
- 支持最后一波Boss怪物。

### 2. 怪物生成器

- 在出生点按波次数据动态生成怪物。
- 支持同一时间存在多个怪物。

### 3. 怪物行为

- **路径跟随**：按预设路点移动。
- **终点行为**：到达萝卜位置后，攻击萝卜（每次减少1点生命），然后自身消失。
- **多样怪物类型**：
  - 不同血量、移动速度、赏金。
  - 特殊属性：飞行怪（无视地面减速效果）、高魔抗怪等。

## 六、战斗与子弹系统

### 1. 子弹系统

- 炮塔射出子弹对象，携带伤害值、目标敌人。
- 子弹沿直线或抛物线轨迹飞向目标，支持不同子弹速度。
- 子弹命中后触发伤害结算和打击特效。

### 2. 伤害结算

- 子弹命中 → 减少敌人血量 → 若敌人死亡：
  - 播放死亡动画。
  - 移除敌人。
  - 增加玩家金币。
  - 更新波次剩余怪物计数。

### 3. 特效触发点

- 子弹击中时产生打击特效（闪光、粒子）。
- 怪物死亡时产生爆炸/消失特效。
- 障碍物清除时产生碎裂特效。

## 七、交互系统

### 1. 鼠标点击交互总则

- 游戏内所有可交互对象（塔位、炮塔、障碍物、怪物）均支持鼠标点击，并具有正确的优先级判断。

### 2. 点击塔位建造炮塔

- **功能**：点击地图上空闲塔位 → 弹出炮塔选择菜单（显示三种基础炮塔及价格） → 点击某一炮塔 → 检查金币 → 扣除金币 → 在塔位上生成炮塔实例。
- **反馈**：炮塔出现动画。

### 3. 点击已建造炮塔进行操作

- **功能**：点击炮塔 → 弹出操作面板（浮于炮塔上方） → 面板包含：
  - 升级按钮（显示下一级所需金币和属性提升预览）。
  - 出售按钮（显示出售可得金币）。
- **升级**：点击升级 → 检查金币 → 扣除 → 炮塔等级+1 → 属性更新 → 面板刷新。
- **出售**：点击出售 → 确认或直接出售 → 获得金币 → 移除炮塔 → 塔位变回空闲。

### 4. 点击怪物/障碍物设置优先攻击目标（索敌交互）

- **功能**：点击地图上的怪物或障碍物 → 将点击的目标设置为**全局炮塔**的优先攻击目标。
- **实现要求**：
  - 点击怪物后，炮塔的下一次搜索目标会优先锁定该怪物，直到目标死亡或超出范围。
  - 点击障碍物同理，炮塔会优先攻击该障碍物（用于快速清障）。
- **取消优先**：可增加“清除优先”按钮，或点击空地取消，或变更优先目标。

## 八、美术资源（专门章节）

### 1. 地图相关美术

- 背景地图图片（或拼接图块）：至少2种场景（草地、雪地）。
- 道路图块：用于标识路径。
- 萝卜模型/动画：静止、受伤（闪红）、被吃（消失动画）。

### 2. 炮塔美术

- 三种基础炮塔，每种3个等级，共9个独立贴图（或逐级变化）。
- 炮塔底座方向：至少4个或8个方向贴图，用于瞄准转向。
- 炮塔攻击动画：炮口闪光、炮身震动等（可选帧动画）。

### 3. 子弹与特效美术

- 每种炮塔的子弹贴图（如近战范围无子弹，但可用范围光圈特效）。
- 子弹击中特效：闪光、粒子爆点。
- 怪物死亡特效：爆炸、烟雾、消失渐变。
- 障碍物清除特效：爆炸碎片、粒子。

### 4. 怪物美术

- 至少3种不同怪物（普通、快速、高血量）的静态贴图或帧动画（行走、死亡）。
- 特殊类型：飞行怪（带翅膀动画）。

### 5. UI美术

- 按钮（开始、退出、暂停、升级、出售等）的正常、悬停、按下状态。
- 金币、血量、波数等图标与数字字体。
- 炮塔选择菜单面板背景。

## 九、附加功能（可选）

### 1. 音效与音乐

- 背景音乐循环播放。
- 音效：建造炮塔、升级、出售、子弹击中、怪物死亡、萝卜受伤。
- 使用独立的音效开关滑块。

### 2. 关卡数据配置化（JSON）

- 所有关卡数据（地图网格、路点、塔位、障碍物、波次等）存储在JSON文件中。
- 游戏启动时加载，便于增加新关卡而不修改代码。

### 3. 简易地图编辑器（独立工具）

- 可视化编辑网格地图。
- 放置/移除障碍物。
- 绘制路径点。
- 标记塔位。
- 导出为JSON文件。
